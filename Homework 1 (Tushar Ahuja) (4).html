Objective:¶

In this part of the assignment, we will extend the academic database by adding four additional tables: course, prereq, advisor, and classroom. We will also populate these tables using data from the corresponding CSV files.

Understanding the Schema¶

I am referring to the schema diagram provided in Files/Homework/data/schema diagram.png to understand the structure of the tables. Ensuring that:

  • Each table has the correct attributes.

  • Primary and foreign key constraints are properly implemented.

  • Required fields are marked as NOT NULL.

  • Unique constraints are applied where necessary.

Table Details:¶

1. course (course_id, title, dept_name, credits)

  • course_id is the Primary Key.

  • dept_name is a Foreign Key referencing the Department table.

  • course_id should be unique.

2. prereq (course_id, prereq_id)

  • Both course_id and prereq_id are Foreign Keys referencing the Course table.

  • Together, they form a Composite Primary Key.

3. advisor (s_id, i_id)

  • s_id is a Foreign Key referencing the Student table.

  • i_id is a Foreign Key referencing the Instructor table.

  • Both columns form a Composite Primary Key.

4. classroom (building, room_no, capacity)

  • (building, room_no) is a Composite Primary Key.

  • capacity cannot be NULL.

Key Improvements¶

1. NOT NULL Constraints

  • All primary key columns are NOT NULL by default.
  • Other essential fields (title, dept_name, credits, etc.) are NOT NULL.

2. UNIQUE Constraints

  • title, dept_name in course: No two courses in the same department can have the same name.
  • s_id in advisor: Each student has only one advisor.
  • i_id, s_id in advisor: Ensures a student-advisor relationship is unique.

3. Foreign Key Constraints

  • ON DELETE CASCADE: If a referenced department, course, or student is deleted, the dependent records are also removed automatically.

4. Check Constraints

  • credits > 0 and capacity > 0: Ensures logical values for credits and classroom capacity.

mycursor = mydb.cursor()

# Creating Tables
create_table_queries = [
    """
    CREATE TABLE IF NOT EXISTS course (
        course_id VARCHAR(10) PRIMARY KEY,  
        title VARCHAR(255) NOT NULL,        
        dept_name VARCHAR(100) NOT NULL,    
        credits INT NOT NULL,              
        UNIQUE(title, dept_name),          
        FOREIGN KEY (dept_name) REFERENCES department(dept_name) ON DELETE CASCADE
    )
    """,
    """
    CREATE TABLE IF NOT EXISTS prereq (
        course_id VARCHAR(10) NOT NULL,
        prereq_id VARCHAR(10) NOT NULL,
        PRIMARY KEY (course_id, prereq_id),  
        FOREIGN KEY (course_id) REFERENCES course(course_id) ON DELETE CASCADE,
        FOREIGN KEY (prereq_id) REFERENCES course(course_id) ON DELETE CASCADE
    )
    """,
    """
    CREATE TABLE IF NOT EXISTS advisor (
        s_id VARCHAR(10) NOT NULL,
        i_id VARCHAR(10) NOT NULL,
        PRIMARY KEY (s_id),                
        FOREIGN KEY (s_id) REFERENCES student(ID) ON DELETE CASCADE,
        FOREIGN KEY (i_id) REFERENCES instructor(ID) ON DELETE CASCADE
    )
    """,
    """
    CREATE TABLE IF NOT EXISTS classroom (
        building VARCHAR(50) NOT NULL,
        room_no VARCHAR(10) NOT NULL,
        capacity INT NOT NULL CHECK (capacity > 0),  
        PRIMARY KEY (building, room_no)  
    )
    """
]

# Execute queries
for query in create_table_queries:
    try:
        mycursor.execute(query)
        mydb.commit()
        print(f"Table created successfully: {query.split()[5]}")  # Extracts the table name
    except mysql.connector.Error as err:
        print(f"Error creating table: {err}")
